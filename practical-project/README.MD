# Cloud Computing Practical Project

## Project Overview

This project demonstrates the practical application of basic cloud computing concepts learned during the internship.

## Objectives

- Understand fundamental cloud computing concepts.
- Learn about different cloud service models.
- Understand virtualization, storage, networking, and security.
- Apply Git and GitHub for project management.

## Concepts Covered

- IaaS, PaaS and SaaS
- Virtualization
- Cloud Storage
- Cloud Networking
- Scalability
- IAM and Cloud Security

## Technologies Used

- HTML
- Git
- GitHub

## Project Outcome

The project provides practical understanding of cloud computing concepts and demonstrates how a simple web project can be created and managed using Git and GitHub.
