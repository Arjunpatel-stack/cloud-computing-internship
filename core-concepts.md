# Cloud Computing – Core Concepts and Skills

## Introduction

Cloud computing is the delivery of computing resources such as servers, storage,
networking and software over the internet.

## Core Concepts

### 1. IaaS
Infrastructure as a Service provides virtual machines, storage and networking
resources.

### 2. PaaS
Platform as a Service provides a platform for developing and deploying applications.

### 3. SaaS
Software as a Service provides ready-to-use software through the internet.

### 4. Virtualization
Virtualization allows multiple virtual machines to run on a single physical
computer.

### 5. Scalability
Scalability means increasing or decreasing resources according to workload
requirements.

### 6. Cloud Storage
Cloud storage allows users to store and access data through the internet.

### 7. Cloud Networking
Cloud networking connects cloud resources and controls communication between them.

### 8. IAM
Identity and Access Management controls who can access cloud resources and
what actions they are allowed to perform.

### 9. Cloud Security
Cloud security protects cloud resources and data using authentication,
permissions, encryption and monitoring.
